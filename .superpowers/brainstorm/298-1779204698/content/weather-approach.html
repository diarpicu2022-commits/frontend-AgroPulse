¿Qué tipo de visualización climática quieres en el mapa?

Cada enfoque tiene diferente nivel de detalle y fuente de datos

🌧 Lluvia 🌡 Temperatura 💨 Viento

A — Capas climáticas sobre el mapa

Tiles de OpenWeatherMap superpuestos: precipitación, temperatura, nubes o viento como capas de color sobre el mapa. Botones para cambiar entre capas. Similar a lo que muestra IDEAM visualmente. Requiere API key de OpenWeatherMap (gratis hasta 1000 calls/día).

Datos por invernadero · Open-Meteo (sin API key)

B — Clima actual por invernadero

Cada marcador de invernadero muestra el clima actual de sus coordenadas GPS (temperatura, humedad, precipitación, descripción). Se obtiene de Open-Meteo, completamente gratis y sin API key. Aparece en el popup al hacer clic en el marcador.

C — Ambos: capas + datos por invernadero (Recomendado)

Combina las capas visuales de OpenWeatherMap con datos precisos de Open-Meteo por invernadero. El mapa muestra la vista regional del clima (como IDEAM) y cada popup muestra los datos exactos del punto GPS del invernadero. Requiere API key de OpenWeatherMap para las capas.

Selecciona el enfoque que prefieres y avísame en el terminal.
